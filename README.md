# BangTurn

A Bangle.js 2 app that tells you when to turn around on a one-hour out-and-back walk.

- Spec: [docs/spec.md](docs/spec.md)
- How it's built: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Tests: `npm test` in a headless emulator, see [tests/README.md](tests/README.md)

## Installing

Upload with the Espruino Web IDE, or add the folder to a personal fork of the
BangleApps loader. Needs the Scheduler (`sched`) app, which is installed by default.
